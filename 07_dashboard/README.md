# 07 · Interactive Analytics Dashboard

> **Goal:** Consolidate all analytical findings into a single, interactive Streamlit dashboard that tells the full visual story of US flight delays.

---

## 🖥️ Dashboard Pages

| Page | Content |
|---|---|
| **Overview** | KPI cards — total flights, delay rate, avg delay, cancellation rate |
| **When to Fly** | Best/worst hours, days, and months to travel |
| **Airline Report** | Carrier-level delay performance rankings and breakdown |
| **Routes** | Airport-level delay heatmap and worst-performing routes |
| **Resolution** | Delay cause analysis — carrier vs. weather vs. NAS vs. late aircraft |

---

## 🚀 Running Locally

```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Place the processed dataset (generated by 06_dimensionality_reduction/)
#    Expected: flight_delay_dashboard_ready.csv in the project root

# 3. Launch
streamlit run app.py
```

Opens at `http://localhost:8501`

## 💡 Design Decisions

- **Plotly** for interactivity (hover tooltips, zoom, cross-filter)
- **`@st.cache_data`** prevents dataset reloads on every widget interaction
- **Multi-page layout** via Streamlit's native `pages/` directory — no custom routing needed
- Sidebar filters are **global** — all pages respond to carrier, airport, and month selection simultaneously
