# 06 · Interactive Analytics Dashboard

> **Goal:** Consolidate all analytical findings into a single, interactive Streamlit dashboard that tells the full visual story of US flight delays.

---

## 🖥️ Dashboard Overview

The dashboard is built with **Streamlit + Plotly** and features:

| Page | Content |
|---|---|
| **Overview** | KPI cards — total flights, delay rate, avg delay, cancellation rate |
| **Delay Deep Dive** | Interactive filters by carrier, airport, month; drill-down charts |
| **Cause Analysis** | Stacked bar: carrier vs. weather vs. NAS vs. late aircraft |
| **Route Intelligence** | Airport-level delay heatmap and worst-performing routes |
| **Temporal Patterns** | Hour-of-day, day-of-week, and seasonal trend lines |

---

## 🚀 Running Locally

```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Place the processed dataset in the expected location
#    (flight_delay_dashboard_ready.csv — generated by 05_dimensionality_reduction/)

# 3. Launch the dashboard
streamlit run app.py
```

The app will open at `http://localhost:8501`

## 💡 Design Decisions

- **Plotly** chosen over Matplotlib for interactivity (hover, zoom, filter)
- Dashboard is **filter-state aware** — all charts respond to the sidebar selections simultaneously
- Data is **cached** with `@st.cache_data` to prevent reloads on interaction
- Layout uses a **3-column KPI row** at the top for immediate impact on load
